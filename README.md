# Library System

Library System adalah aplikasi sederhana berbasis Laravel yang digunakan untuk mengelola data perpustakaan.

## Fitur

- Menampilkan daftar buku
- Menyimpan data buku ke database
- Menggunakan Migration untuk membuat tabel books
- Menggunakan Model dan Eloquent untuk mengambil data
- Menggunakan Seeder untuk mengisi data buku

## Struktur Data Buku

Data buku terdiri dari:

- ID
- Judul
- Penulis
- Tahun Terbit
- Stok

## Teknologi

- Laravel
- PHP
- MySQL
- Blade
- Eloquent ORM
