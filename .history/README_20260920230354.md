# Library System

## Deskripsi
Aplikasi web sederhana untuk pengelolaan perpustakaan digital (daftar buku, detail buku, kategori, dan member). Dibuat menggunakan **Laravel 13** tanpa database untuk tugas **Pertemuan 6 - Routing, Controller, dan Blade**.

## Fitur
* **Dashboard (`/dashboard`)**: Statistik singkat sistem.
* **Books (`/books`)**: Daftar buku, penulis, dan tahun terbit.
* **Book Detail (`/books/{id}`)**: Detail buku berdasarkan ID.
* **Categories (`/categories`)**: Daftar kategori buku.
* **Members (`/members`)**: Daftar anggota perpustakaan.

## Cara Jalankan Project

1. Clone repository:
   git clone https://github.com/adityangrhaa10-sketch/library-system.git
   cd library-system

2. Install dependency:
   composer install

3. Copy file .env:
   cp .env.example .env

4. Generate key:
   php artisan key:generate

5. Jalankan server:
   php artisan serve

6. Buka di browser:
   http://127.0.0.1:8000/dashboard
